# Architecture checks

## English

The boundary script checks the Phase 0 Cargo dependency direction and required
crate ownership. It is structural evidence, not a substitute for domain design.

## 日本語

boundary script は Phase 0 の Cargo 依存方向と crate ownership を確認する。これは構造の
evidence であり、domain design の代替ではない。

## 中文

边界脚本检查 Phase 0 的 Cargo 依赖方向和 crate 归属。它是结构证据，不替代领域设计。
