# goods-runtime

## English

This crate owns future runtime composition and lifecycle orchestration. Phase 0
defines only module ownership and the `GoodsRuntime` name; no state machine or
runtime behavior exists.

## 日本語

この crate は将来の runtime composition と lifecycle orchestration を所有する。Phase 0
では module ownership と `GoodsRuntime` の名前だけを定義し、state machine や runtime
挙動は存在しない。

## 中文

此 crate 负责未来的 runtime 编排和生命周期编排。Phase 0 只定义模块归属和
`GoodsRuntime` 名称，不包含状态机或 runtime 行为。
