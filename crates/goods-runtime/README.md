# goods-runtime

## English

This crate owns runtime composition and lifecycle orchestration. Phase 1
provides a product-independent `GoodsRuntime` that composes Observe → Assess;
there is no state machine and no Need, Care, Memory or Learning behavior.

## 日本語

この crate は runtime composition と lifecycle orchestration を所有する。Phase 1 では商品非依存の
`GoodsRuntime` が Observe → Assess を compose する。state machine と Need、Care、Memory、Learning の挙動はない。

## 中文

此 crate 负责 runtime 编排和生命周期编排。Phase 1 提供与商品无关的 `GoodsRuntime` 来编排 Observe → Assess；不包含状态机，
也不实现 Need、Care、Memory 或 Learning 行为。
