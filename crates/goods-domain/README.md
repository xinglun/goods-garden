# goods-domain

## English

This crate owns the Goods Garden domain language. Phase 0 contains only names,
module boundaries and empty placeholder types. It has no external dependencies.

## 日本語

この crate は Goods Garden の domain language を所有する。Phase 0 では名前、module
boundary、空の placeholder type だけを置き、外部依存を持たない。

## 中文

此 crate 负责 Goods Garden 的领域语言。Phase 0 只包含名称、模块边界和空的占位类型，
不依赖外部 crate。
