# goods-domain

## English

This crate owns the Goods Garden domain language. Phase 1 defines the minimal
Goods Identity, Goods Profile, Observation, Expectation, Goods State and Health
Assessment needed by the synthetic demo. It has no external dependencies.

Goods Identity、Goods Profile、Observation、Expectation、Goods State、Health Assessment を定義する。外部依存は持たない。
