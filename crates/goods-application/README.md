# goods-application

## English

This crate owns use cases and ports. It may depend on `goods-domain`, but it
does not know runtime composition or concrete adapters. Phase 0 keeps every
use case and port behavior-free.

## 日本語

この crate は use case と port を所有する。`goods-domain` に依存できるが、runtime の
composition や具体的な adapter は知らない。Phase 0 では挙動を実装しない。

## 中文

此 crate 负责用例和端口。它可以依赖 `goods-domain`，但不感知 runtime 编排或具体
adapter。Phase 0 的所有用例和端口都不实现行为。
