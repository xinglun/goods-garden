# AI Cockpit Repository Protocol

## English

This directory contains repository-bound AI Cockpit protocol artifacts. The
Runtime is external and its source is not copied here. Generated files are
owned by AI Cockpit and must be changed through its commands. Human-owned
project declarations under `.ai/project/` describe capabilities, success
criteria and profile policy.

Use the active Work Item Contract as the authority for scope. Treat missing
evidence as missing, and never infer approval or completion from fluent text.
