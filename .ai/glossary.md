# AI Cockpit Project Glossary

## English

- `KNOWN`: directly supported by repository or command evidence.
- `INFERRED`: an explicitly marked interpretation.
- `UNKNOWN`: not established by available evidence.
- `UNAVAILABLE`: expected evidence cannot currently be accessed.
- `CONFLICTING`: available sources disagree.
- `protected`: a semantic area requiring human review.
- `Work Item`: the bounded unit of intent, scope, authority and evidence.

## 日本語

- `KNOWN`: repository または command evidence が直接支持する事実。
- `INFERRED`: 明示的に marked された解釈。
- `UNKNOWN`: 利用可能な evidence で確立されていない事実。
- `UNAVAILABLE`: 必要な evidence に現在アクセスできない状態。
- `CONFLICTING`: 利用可能な source が一致しない状態。
- `protected`: human review が必要な semantic area。
- `Work Item`: intent、scope、authority、evidence を bounded に扱う単位。

## 中文

- `KNOWN`：由仓库或命令证据直接支持的事实。
- `INFERRED`：明确标记过的解释。
- `UNKNOWN`：现有证据尚未建立的事实。
- `UNAVAILABLE`：当前无法访问所需证据。
- `CONFLICTING`：现有来源互相冲突。
- `protected`：需要人工 review 的语义区域。
- `Work Item`：限定 intent、scope、authority 和 evidence 的工作单元。
