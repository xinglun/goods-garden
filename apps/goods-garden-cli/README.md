# goods-garden-cli

## English

The CLI is the future human-facing application entry point. In Phase 0 it is
an intentionally empty binary and exposes no product behavior.

## 日本語

CLI は将来の human-facing application entry point である。Phase 0 では意図的に空の
binary とし、商品挙動を公開しない。

## 中文

CLI 是未来面向人的应用入口。Phase 0 中它是刻意保持为空的 binary，不提供商品业务行为。
