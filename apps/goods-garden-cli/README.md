# goods-garden-cli

## English

The CLI is the human-facing entry point for the bounded Phase 1 demo. Running
`cargo run -p goods-garden-cli -- demo` loads the local synthetic fixture and
prints identity, observation, expectation and Health Assessment. It does not
connect to POS or any external service.

## 日本語

CLI は Phase 1 の bounded demo における human-facing entry point である。
