# Contributing to Goods Garden

## English

Phase 0 contributions must preserve the declared workspace boundaries and add
only names, traits, structs, module wiring, documentation, tests or CI needed
for the foundation. Keep business behavior for a later reviewed phase.

Before proposing a change, read `AGENTS.md`, `docs/north-star.md`, the relevant
architecture document and the active AI Cockpit Contract. Mark unknown facts as
`UNKNOWN`; do not infer real SEJ, POS or store operations.

Run the four Cargo quality commands and the architecture script. Human-facing
documents must be equivalent in English, Japanese and Chinese. Changes to
protected semantic areas require human review and an updated Work Item.
