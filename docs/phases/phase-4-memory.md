# Phase 4 — Memory

## English

Goods remembers what happened, who helped, what action was taken and what the
result was. Establish Relationship Memory without inventing retention policy.

## 日本語

Goods が何が起き、誰が助け、どの action を行い、結果が何だったかを記憶する。retention policy を創作せず Relationship Memory を作る。

## 中文

商品记住发生了什么、谁帮助过、采取了什么行动以及结果是什么。在不编造保留策略的前提下建立 Relationship Memory。
