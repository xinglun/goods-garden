# Phase Roadmap

## English

The roadmap is intentionally sequential. Each phase adds a reviewed domain
capability only after the previous boundary and evidence are clear. Phase 1 is
the current phase; Phase 0 established the foundation. See
[Phase 1 — First Living Goods](phase-1-first-living-goods.md) for the current
implementation boundary.

## 日本語

roadmap は意図的に sequential である。前 phase の boundary と evidence が明確になってから、
review 済みの domain capability を追加する。現在は Phase 1 で、Phase 0 は foundation を確立した。
現在の実装 boundary は [Phase 1 — First Living Goods](phase-1-first-living-goods.md) に記載する。

## 中文

路线图刻意保持顺序。只有前一阶段的边界和证据清晰后，才增加经过 review 的领域能力。当前是 Phase 1，Phase 0 已建立工程基础。
当前实现边界见 [Phase 1 — First Living Goods](phase-1-first-living-goods.md)。
