# Phase Roadmap

## English

The roadmap is intentionally sequential. Each phase adds a reviewed domain
capability only after the previous boundary and evidence are clear. Phase 0 is
the current phase.

## 日本語

roadmap は意図的に sequential である。前 phase の boundary と evidence が明確になってから、
review 済みの domain capability を追加する。現在は Phase 0。

## 中文

路线图刻意保持顺序。只有前一阶段的边界和证据清晰后，才增加经过 review 的领域能力。当前是 Phase 0。
