# Phase 3 — Care

## English

Goods identifies when it cannot resolve a Need alone and who may help. Add
CareRequest, Caregiver, Human Feedback and CareAction. This is the first
two-way interaction: `Goods ↔ Human`.

## 日本語

Goods が自分だけでは Need を解決できず、誰が助けられるかを知る。CareRequest、Caregiver、Human Feedback、CareAction を追加する。
初めて `Goods ↔ Human` の双方向 interaction が生まれる。

## 中文

商品识别自己无法解决 Need 的情况以及谁可以帮助。增加 CareRequest、Caregiver、Human Feedback、CareAction，第一次形成
`Goods ↔ Human` 双向交互。
