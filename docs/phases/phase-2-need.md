# Phase 2 — Need

## English

Goods discovers what is uncomfortable and what it needs. Add Deviation, Need,
Urgency and Need Conflict so a KPI can become an explainable business Need,
not only an Alert.

## 日本語

Goods が何に問題があり何を必要とするかを発見する。Deviation、Need、Urgency、Need Conflict を追加し、KPI を単なる
Alert ではなく explainable な business Need に変換する。

## 中文

商品发现哪里不舒服以及需要什么。增加 Deviation、Need、Urgency、Need Conflict，使 KPI 能转换为可解释的经营 Need，而不只是 Alert。
