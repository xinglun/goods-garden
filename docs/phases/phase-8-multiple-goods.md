# Phase 8 — Multiple Goods

## English

Add salmon rice ball, coffee, sandwich and bento only to prove that Goods
Intelligence is a class of capability while a concrete good is an object or
instance. Do not add products merely for quantity.

## 日本語

salmon rice ball、coffee、sandwich、bento を追加する目的は数を増やすことではなく、Goods Intelligence が class of capability、
concrete good が object/instance であることを証明すること。

## 中文

加入鲑鱼饭团、咖啡、三明治和便当的目的不是堆商品，而是证明 Goods Intelligence 是能力 Class，具体商品是 Object 或 Instance。
