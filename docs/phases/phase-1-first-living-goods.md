# Phase 1 — First Living Goods

## English

Goal: give one synthetic tuna-mayo reference object its first State. Implement
only Goods Identity, Goods Profile, Observation, Goods State, Expectation and
Health Assessment. The endpoint is the answer “Am I okay?”; do not implement
asking for care.

## 日本語

目標は synthetic な tuna-mayo reference object に最初の State を与えること。Goods Identity、Goods Profile、
Observation、Goods State、Expectation、Health Assessment だけを実装し、終点は「今、自分は大丈夫か」に答えること。
care request は実装しない。

## 中文

目标是让一个 synthetic tuna-mayo reference object 第一次拥有 State。只实现 Goods Identity、Goods Profile、Observation、
Goods State、Expectation、Health Assessment。终点是回答“我现在好不好”，不实现求助。
