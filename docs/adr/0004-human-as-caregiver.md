# ADR 0004: Human as Caregiver

## English

### Context

Human interaction should express a relationship with a good, not command an
opaque AI persona.

### Decision

Use `Caregiver` for the human role and model the relationship as `Goods ↔ Caregiver`.

### Alternatives

Model human as an AI operator, task executor or end-user only.

### Consequences

Care authority, feedback and escalation must be explicitly designed later.

### Status

Accepted for Phase 0.
