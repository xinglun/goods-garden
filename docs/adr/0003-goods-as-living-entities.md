# ADR 0003: Goods as Living Entities

## English

### Context

The product needs a model richer than a passive data object.

### Decision

Model a good as a living business entity with the provisional loop State → Need
→ Care → Action → New State → Memory/Learning.

### Alternatives

Keep a dashboard-only model or make an unconstrained persona chatbot.

### Consequences

Future behavior must be grounded in domain state and evidence; the metaphor is
not a consciousness claim.

### Status

Accepted for Phase 0; domain semantics remain provisional.
